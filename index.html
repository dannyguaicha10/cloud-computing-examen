Tecnologías de Cloud Computing

Cloud Computing (Computación en la Nube)

Es la entrega de servicios de computación —incluidos servidores, almacenamiento, bases de datos, redes, software y análisis— a través de Internet ("la nube") para ofrecer innovación rápida, recursos flexibles y economías de escala.

SaaS (Software as a Service)

Modelo de distribución de software donde el soporte lógico y los datos que maneja se alojan en servidores de una compañía de tecnologías de información y comunicación, a los que se accede vía Internet desde un cliente (ej. Google Workspace, Office 365).

PaaS (Platform as a Service)

Entorno de desarrollo e implementación completo en la nube, con recursos que permiten entregar desde aplicaciones sencillas basadas en la nube hasta aplicaciones empresariales sofisticadas sin gestionar la infraestructura subyacente (ej. Heroku, Google App Engine).

IaaS (Infrastructure as a Service)

Infraestructura informática instantánea, aprovisionada y administrada a través de Internet. Permite alquilar servidores virtuales, almacenamiento y redes bajo demanda (ej. Amazon EC2, Microsoft Azure).

Virtualización

Tecnología que permite crear servicios de TI útiles mediante recursos que están tradicionalmente vinculados al hardware. Permite utilizar toda la capacidad de una máquina física distribuyendo sus capacidades entre muchos usuarios o entornos mediante máquinas virtuales (VMs).

Docker

Plataforma de código abierto que automatiza el despliegue de aplicaciones dentro de contenedores de software ligeros y portátiles, garantizando que el software funcione de manera uniforme en cualquier entorno.
